# unison-website

The commercial website and documentation for Unison: a component library and the Figma plugin that writes its code.

Bootstrapped from `unison-playground-web`: Next.js 16 (App Router, Turbopack, React Compiler), React 19, Tailwind CSS v4 and Biome, managed with Bun.

```sh
bun install
bun dev        # http://localhost:3000
bun run build
bun run lint
```

See AGENTS.md for conventions.
