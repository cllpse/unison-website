# figma-website

The commercial website and documentation for the Figma component library.

Bootstrapped from `figma-playground`: Next.js 16 (App Router, Turbopack, React Compiler), React 19, Tailwind CSS v4 and Biome, managed with Bun.

```sh
bun install
bun dev        # http://localhost:3000
bun run build
bun run lint
```

Brand colors in `src/app/globals.css` mirror the library's `COLORS` tokens, and the product name lives in `src/lib/site.ts`.
