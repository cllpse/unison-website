# unison-website

The commercial website and documentation for Unison: a component library and the Figma plugin that writes its code.

Part of [Unison](https://github.com/cllpse/unison), alongside
[unison-components](https://github.com/cllpse/unison-components),
[unison-plugin](https://github.com/cllpse/unison-plugin),
[unison-playground-web](https://github.com/cllpse/unison-playground-web) and
[unison-playground-expo](https://github.com/cllpse/unison-playground-expo).

Bootstrapped from `unison-playground-web`: Next.js 16 (App Router, Turbopack, React Compiler), React 19, Tailwind CSS v4 and Biome, managed with Bun.

```sh
bun install
bun dev        # http://localhost:3000
bun run build
bun run lint
```

See AGENTS.md for conventions.
